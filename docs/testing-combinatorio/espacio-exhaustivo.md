**Espacio exhaustivo teórico = 46.080 combinaciones**

## Interpretación

Una estrategia exhaustiva requeriría evaluar teóricamente 46.080
combinaciones de las ocho variables modeladas.

Este volumen hace poco práctica una estrategia exhaustiva, por lo que
el espacio será reducido posteriormente mediante testing combinatorio
2-wise (pairwise).

Por lo tanto, las 46.080 combinaciones representan el espacio
cartesiano teórico previo a la aplicación de restricciones.
